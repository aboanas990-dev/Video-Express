# VIDEO EXPRESS

محرر فيديو وحركة يشبه After Effects، يعمل في المتصفح من ملف HTML واحد، مع أدوات ذكاء اصطناعي وتسجيل للشاشة.

> برمجة: حسن الفيفي · Hassan Alfaifi — للدعم: aboanas990@yahoo.com

## التشغيل
1. افتح `video-studio8.html` في Chrome أو Edge.
2. يحتاج اتصالًا بالإنترنت عند أول فتح لتحميل الخطوط، وعند أول استخدام لأدوات الذكاء الاصطناعي لتحميل نماذجها.
3. للتصدير السريع ولتفريغ الكلام بأسرع شكل يُفضّل متصفح يدعم WebGPU.

## الميزات
- **التكوين والتحرير:** طبقات فيديو وصورة ونص وأشكال وأقنعة، خط زمني بمفاتيح حركة، محرر المنحنيات (Graph Editor) وتنعيم المفاتيح (Easy Ease)، تقسيم الطبقة، علامات، وشبكة وهوامش أمان.
- **العارض:** أدوات التحديد واليد والتكبير والأشكال، تكبير ودقة معاينة، التقاط إطار، ومعاينة على كامل الشاشة.
- **الصوت:** تسجيل تعليق صوتي أثناء تشغيل الفيديو مع مستوى المايكروفون.
- **الترجمة:** استيراد ملف SRT، وتفريغ الكلام تلقائيًا إلى ترجمة بنماذج Whisper (tiny وbase وsmall) تعمل داخل المتصفح، وتصدير SRT.
- **الذكاء الاصطناعي:** إزالة الخلفية وكشف الوجوه داخل المتصفح (MediaPipe) دون رفع الصور. توليد الصور والنصوص عبر خدمة pollinations.ai الخارجية، ويسألك البرنامج قبل إرسال أي نص إليها.
- **تسجيل الشاشة:** تبويب مستقل لتسجيل الشاشة وحفظ تسجيلات الجلسة.
- **التصدير:** قائمة تصدير (Render Queue) بصيغ MP4 وWebM.
- **استوديو الصور:** يُفتح في صفحة مستقلة من داخل البرنامج.
